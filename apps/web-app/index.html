Technical Specifications & Architecture Report

Grounding evidence and specs based on Manish Dadhwal's Optical File Transfer Report.

File Container & Fountain Coding

Uses Luby Transform rateless erasure codes. Payload is split into K source blocks and encoded into randomized XOR repair packets.

  • CRC32C checksum protection per frame
  • SHA-256 post-reconstruction validation
  • AES-256-GCM client-side encryption

Computer Vision & Homography

Detects 4 corner finder alignment patterns to compute a 3x3 homography perspective transform ($H$), enabling accurate frame sampling under tilt and skew.

  • Dynamic color swatch centroid calibration bar
  • Bilinear pixel interpolation sampling
  • Dropless recovery with up to 50% frame loss
